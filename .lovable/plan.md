## Что делаем

Полная замена текущего сайта. Старое (Karl Popper/Parliamentary, AI-тьютор/AI-судья/AI-спарринг как ядро, editorial-газета) уходит. Новое ядро — human-to-human матчинг с недельным ритмом «День дебатов», AI только точечно.

Первый проход покрывает ядро UX: **Главный экран**, таб **День дебатов**, таб **Профиль**, плюс необходимый каркас (навигация, стиль, роутинг, БД). Обучение / Тренировка / лобби комнат / LiveKit / модерация — следующими проходами.

## Дизайн-система (новая)

- Фон `#F7F3EC` (кремовый), hero-поверхности `#1A1A2E`, акцент `#E8562D`, поверхность стола `#EEEDFE`.
- Карточки: белые, border `0.5px`, radius 12–18px, без теней/градиентов.

- Мотив «идея → критерий → аргумент» как повторяющийся типографический элемент.

Новые/переименованные:

## База данных (миграция)

Добавляю таблицы под новое ядро (RLS + GRANT по правилам):
- `debate_weeks` — неделя: `week_start`, `topic`, `topic_reveal_at`, `pro_percent`, `con_percent`, `rounds_count`, `listeners_total`, `ai_summary`.
- `player_ratings` — на пользователя: `mastery`, `mastery_trend_week`, `knock`, `moderator`, `league` (`zonal`/`republic`), `matches_played`.
- `live_rooms` — активные комнаты: `format` (`1v1`/`2v2`/`roundtable`), `topic`, `listeners`, `is_live`, `started_at`.
- `roundtables` — стол: `topic`, `moderator_id`, `participants` (jsonb), `opinion_before`, `opinion_after`, `best_speaker_id`, `starts_at`.
- `week_highlights` — «лучший раунд дня», ссылки на запись.

Профиль расширяю: `birthdate`, `parent_email`, `parent_confirmed_at`, `languages` (jsonb), `avatar_url`. Существующий `profiles.role` переиспользую для student/adult/moderator/admin.

Первый проход рендерит эти экраны на demo-seed (несколько строк, вставленных той же миграцией), чтобы UI сразу выглядел живым; полноценные потоки записи данных придут со следующими фичами.

## Главный экран — сборка

Компоненты в `src/components/home/`:
- `<CountdownHero>` — тёмная карточка, тикающий отсчёт до ближайшей субботы (клиентский таймер), под ним `<WeekTopicReveal>` с двумя состояниями (замок / оранжевый бейдж + тема) на основе `topic_reveal_at`.
- `<LastWeekBanner>` — тонкая белая полоска, тема + мини bar за/против, тап → `/debate-day?week=prev`.
- `<PrimaryActions>` — «Найти соперника» 55% (заглушка → toast «Скоро»), «Тренировка» 45% → `/training`.
- `<MyRatingCard>` — из `player_ratings` для текущего юзера (или CTA логина).
- `<LiveNow>` — красная точка + агрегаты по `live_rooms`: строка «Тема недели», две карточки 1×1 / 2×2 рядом (комнаты + суммарные слушатели), баннер круглого стола лавандовый с наложенными аватарами.

## Таб «День дебатов»

`/debate-day` — единый экран, режим (итоги / предстоящее) определяется днём недели и наличием данных за выбранную неделю; переключение недель стрелками.
Карточки: тема дня (bar за/против), лучший раунд (тук-счётчик + «Слушать» → заглушка), круглый стол (сдвиг мнения), рейтинг недели (топ-2 + своя строка оранжевым), AI-обзор с явным бейджем «AI-обзор», «Смотреть все записи».

## Таб «Профиль»

`/profile` — свой: аватар/имя/лига, три числа (мастерство / тук / модератор — прочерк, если 0), таб-переключатель Мастерство/Тук/Модератор, список лидеров лиги со своей подсвеченной строкой, «Вся лига →».
`/profile/$userId` — тот же макет, вместо шестерёнки — кнопка «Challenge» (заглушка-toast).
Переключатель языка и logout — внутри своего профиля.

## Что НЕ входит в этот проход (явно)

LiveKit-комнаты и реальный live-звук; матчмейкинг и Challenge-флоу целиком; регистрация несовершеннолетних с родительским согласием; модерация жалоб; полный контент Обучения и Тренировки; массовое вещание. Всё это — следующими итерациями поверх заложенного каркаса.

## Технические заметки

- Стек: TanStack Start + Tailwind v4 + shadcn/ui + Lovable Cloud (Supabase) — как есть.
- Данные читаются в лоадерах через `createServerFn` с публичным ключом для публичных агрегатов (комнаты, тема недели, дайджест) и через `requireSupabaseAuth` для своего рейтинга/профиля.
- `AuthListener` и провайдеры в `__root.tsx` сохраняю; выпиливаю только `AITutorWidget` и `Footer` из общего лейаута.
- Никаких Supabase Edge Functions не создаю.
